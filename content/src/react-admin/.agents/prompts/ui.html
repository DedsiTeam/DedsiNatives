UI Specification • 欧美科技风格 & 扁平化规范

前端界面优化与 视觉设计规范说明书

本说明文档定义了项目 UI 重构的色彩 Token、8px 间距系统、12px/8px 圆角控制、微动效（150ms-250ms）及自然交互状态。仅调整前端视觉与交互状态，不修改任何业务逻辑与数据结构。

预览所有交互组件 查看 Palette 色盘

01 总体设计原则

明确 UI 调整的目标范围与欧美扁平化科技产品视觉定位。

定位方向

欧美科技产品风格、扁平化、简洁、现代、专业。参考现代 SaaS、AI 工具与开发者平台。

视觉与留白

具有清晰的视觉层级、充足留白和精致细节。避免复杂装饰、拟物化、过度渐变与厚重阴影。

边界要求

仅优化前端布局、样式与交互状态。不修改业务逻辑、接口请求、数据结构与功能流程。

03 8px 间距系统与圆角控制

严格采用 8px 梯级倍数间距与统一的 12px 卡片圆角及 8px 控件圆角。

圆角控制 (Border Radius)

卡片圆角：12px
容器卡片、Modal 模态框统一使用 12px 圆角及浅色微阴影。
控件圆角：8px
所有按钮、输入框、下拉框、标签一律统一使用 8px 圆角。
页面宽度建议： 最大宽度控制在 1200px 至 1440px，两端保持 32px 充足留白。
