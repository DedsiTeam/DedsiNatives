## 前后端契约（涉及 API 或跨端协作时必填）

进入后端或前端编码前，主智能体必须确认本节完整且无冲突，并把采用的契约写入 Loop 执行日志。不适用的字段应明确写“无”及原因，不得留空后由实现智能体猜测。

### 接口契约

- 接口路径：`/xxx/yyy`
- HTTP 方法：`GET | POST | PUT | DELETE`
- 认证方式：`Anonymous | Bearer | Internal`
- 请求字段：列出字段名、类型、是否必填和说明
- 响应字段：列出字段名、类型和说明
- 分页字段：列出页码、页大小、总数等；不分页时说明
- 状态码：列出成功与失败状态码
- 错误结构：列出错误码、消息和详细信息字段

### 后端实现约束

- 领域层：聚合、值对象、领域事件、仓储或查询契约的变化
- 基础设施：EF Core 映射、仓储实现、索引和数据库迁移要求
- Endpoints/API：Endpoint、Request/Response、Validator、应用事件处理器、路由和权限要求
- Host 接线：模块组合、认证、中间件或宿主配置要求；无变化时明确说明
- 数据规则：唯一性、状态流转、并发、审计和分页规则

### 前端实现约束

- 页面/组件：列表、详情、表单、弹窗或其他交互范围
- API 层：DTO、Service、请求方法和导出要求
- 类型安全：输入、输出和页面状态类型；禁止使用 `any`
- 交互：加载、空状态、错误提示和提交成功反馈
